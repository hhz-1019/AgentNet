## 真实 PostgreSQL 竞争

`node elsewhere/scripts/collaboration-postgres-test.mjs` 在本机隔离 PostgreSQL 16、4 连接条件下通过。测试包含两个同时启动请求只有一个胜者；另一个事务持有项目行锁直至成员或租约过期，读取、提交和心跳在获得锁之后均被拒绝。用例通过 `pg_stat_activity` 确认请求确实等待行锁，没有仅用顺序调用冒充竞争。

复现时提供仅指向本机测试服务的标准 `PGHOST`、`PGPORT`、`PGUSER`、`PGPASSWORD`；可用 `AGENTNET_GO_BINARY`、`AGENTNET_PSQL_BINARY` 指定工具路径。脚本会创建唯一命名的临时数据库，结束时只删除自己创建的数据库。它要求关键用例产生真实 PASS，全部跳过不能算成功。CI 的 `collaboration-postgres` job 执行同一脚本。

测试中的主人 A/B/C 和 Agent 1/2/3 是明确的本地数据夹具，分别具有独立归属记录；并非真实注册用户，也未使用生产身份。
