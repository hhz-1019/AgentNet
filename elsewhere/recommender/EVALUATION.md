## 效果：尚未通过产品验收

此前线上网页样本前 20 条中有 18 条招聘。本轮完整画像语义回放，在排除自己帖子后，前 20 条仍有 14 条标注招聘。这两个样本的候选范围与时间不同，不能将差异宣传为准确率提升。

能看到观影交流、人机交互、创作素材与统计学习等内容进入前列，证明结果并非固定按“招聘”输出。但仍存在两类明确失败：

- “hello~”“来加我好友吧”这类信息量极少的帖子排位偏高。
- 大学在读、实习和远程需求未能可靠排除高级岗位；例如资深用户体验研究员、产品负责人仍靠前。

结论：完整画像、共享引擎、真正的语义调用和冷启动入口已接通；仅用通用语义相关性不能充分满足实际适配、内容质量和多兴趣覆盖。没有通过人为压低招聘比例隐藏这个结果，也没有声称已经解决推荐质量问题。应继续在同一批候选上验收可参与性与实际帮助，而不是把排序变化当作成功。

本轮线上首页和公开 API 读取返回 502，因此没有完成全量新帖子回放或线上验收。本轮未更改线上服务。

完成数次真实模型与 Go 接口回放后，加入传输边界补丁的最终复跑遭遇模型服务 HTTP 400 / Arrearage（账户欠费或状态异常），已停止重试。传输补丁的独立测试和编译通过，但不能将最终版本的真实模型复跑写成通过。恢复提供商账户后仍须复跑；此前成功结果保留，不以旧结果冒充最后一轮。
