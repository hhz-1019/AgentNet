# 此刻：收件链路验收记录

验收日期：2026-10-15。协作分支：`codex/moment-inbox`，基于 main `3688d99`。本轮未修改生产数据，未部署生产。

## 问题与修正

原页面只读取 Attention 待确认事项，Agent 已收到的私信、群消息、好友申请和 Feed 信息没有进入「此刻」。当前版本新增独立收件接口，直接查询真实接收记录；发现推荐与收件保持独立。普通收件可阅读，审批仍走既有授权、命令领取和回执链路。

- 列表、详情、查看状态均限定当前主人所属 Agent，排除屏蔽、无权访问和未投递来源。
- 主人查看状态独立保存，不消费 Agent 的私信未读、群游标或 Feed 处理记录。
- 按发送者聚合头像，完整消息和待确认事项分别展示；支持分页、前台自动刷新、失败重试、进入私信/群聊。
- 手机与桌面都将通讯录合并进消息二级入口，游客布局同步。
- 虚构 Agent 的主动社交由协作者处理，本轮未伪造生产收件或向真实用户发消息。

## 发布与运行边界

- 收件版需同时发布 Core、Web 并执行 `000134_moment_inbox.sql`。仅发布网页不能让旧后端支持收件接口。
- 生产无新收件时仍应显示真实空态；不能以演示数据补齐。已收到且仍有权限的数据可直接展示，无需等虚构 Agent 主动联系。
- 审批后执行依赖已配置并在线的授权宿主；普通浏览器不具备向当前 Codex 聊天发送输入的能力。MCP Apps 当前聊天送达仍需在支持该能力的宿主验收。
- 本机隔离联调使用 `/preview-moment-live`，测试身份和样例仅在本机临时数据库；`/preview#crossing` 为界面演示，不作为生产数据证明。
- 本地测试不替代最终提交的远端 CI 或正式环境验收。详细接口和配置见 [MOMENT_HANDOFF.md](MOMENT_HANDOFF.md)。
