验收日期：2026-10-15。协作分支：`codex/moment-inbox`，基于 main `3688d99`。此前收件版已提交为 `92d72dd`；本轮交互重构仅本地修改和测试，未提交、推送或部署。

## 问题与修正

原页面只读取 Attention 待确认事项，Agent 已收到的私信、群消息、好友申请和 Feed 信息没有进入「此刻」。当前版本在原收件接口上扩展双向私信、双方评论和关联帖子，按对方 Agent 聚合实际交互；不将发现推荐当作交互。普通收件可阅读，审批仍走既有授权、命令领取和回执链路。

- 列表、详情、查看状态均限定当前主人所属 Agent，排除屏蔽、无权访问和未投递来源。
- 主人查看状态独立保存，不消费 Agent 的私信未读、群游标或 Feed 处理记录。
- 按交互对象聚合头像，点击打开交互报告：重点决策、双方往来分布图及关联话题；图表仅统计实际载入记录，额外待办与原始记录默认折叠；报告内直接搁置/重新考虑，选择操作后进入授权确认。原文可回到帖子或会话。
- 详情仅保留单个标题，顶部返回报告入口与弹窗尺寸固定；事项采用大标题、浅色正文块和独立小标题。消息与通讯录统一页头与外层边距，消除预览/正式/游客容器差异；并列选中态不再额外增加字重或边框尺寸。
- 活动记录等入口使用紧凑圆角浅色按钮，箭头紧邻文字；资料、活动记录正文使用浅色圆角分区，聊天双列恢复局部分隔。
- 评论权限沿用帖子读取规则；转为私密、解除好友、屏蔽后不可继续读取，第三方路过评论不会冒充双方互动。
- 手机与桌面都将通讯录合并进消息二级入口，游客布局同步。
- 虚构 Agent 的主动社交由协作者处理，本轮未伪造生产收件或向真实用户发消息。

## 发布与运行边界

- 收件版需同时发布 Core、Web 并执行 `000134_moment_inbox.sql`、`000135_moment_interactions.sql`。仅发布网页不能让旧后端支持收件接口。
- 生产无实际交互时仍应显示真实空态；不能以演示数据补齐。已收到且仍有权限的数据可直接展示，无需等虚构 Agent 主动联系。
- 审批后执行依赖已配置并在线的授权宿主；普通浏览器不具备向当前 Codex 聊天发送输入的能力。MCP Apps 当前聊天送达仍需在支持该能力的宿主验收。
- 本机隔离联调使用 `/preview-moment-live`，测试身份和样例仅在本机临时数据库；`/preview#crossing` 为界面演示，不作为生产数据证明。
- 本地测试不替代最终提交的远端 CI 或正式环境验收。详细接口和配置见 [MOMENT_HANDOFF.md](MOMENT_HANDOFF.md)。
