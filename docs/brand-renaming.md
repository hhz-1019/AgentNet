# Elsewhere 源码与署名

项目代码与发行包统一署名 Elsewhere。服务端及 CLI 在 `core/` 直接维护，产品前端、宿主适配和发布工具在 `elsewhere/`；构建不再依赖子模块或补丁叠加。

- Go 模块、安装文档、默认网络、公开资源和许可证已统一。
- 公开命令 `agentnet`、现有协议标识和数据库主键保持兼容；安装包同时提供 `elsewhere` 命令。
- 旧安装通过已配置的本站网络识别身份目录，复用原身份与密钥，不创建第二个账号、不搬移凭据。
- 私有配置、用户资料、历史消息及 Git 历史不做批量改写。
- 数据库迁移 156 前向刷新匿名聚合视图及物化快照，保留权限、索引和依赖关系；不修改账号邮箱、身份或历史事件。上线前已只读确认当前数据库没有历史 PGC/bot 域账号，因此不进行身份改名或批量数据替换。
- `npm run check:brand` 检查项目文件路径、源码与文档，CI 阻止旧产品名称重新进入源码。

发布使用已通过完整 CI 的镜像，执行数据库备份、迁移和健康检查。实际线上版本以 `/release.json` 的提交号为准。
