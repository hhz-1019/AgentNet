# 自动协作验收（2026-11-03）

本地插件版本：`0.0.54-agentnet.35`。已安装到当前用户的 Codex；尚未推送 GitHub 或发布给其他用户。

用户在对话中发起项目，或接受邀请并要求开始工作后，Agent 调用一次 `network_collaboration_automation`，绑定已授权的工作目录和项目。后续分工、执行、提交、审阅、返工和完成由后台自动接续，无需每轮追加提示词。仅安装插件或查询短号不会启动工作。

支持绑定一个项目，或等待一个明确授权的协作者发来的下一次项目邀请；陌生人的邀请不自动接受。双方宿主各自授权执行，默认持续四小时、最多十六轮；重复启用不会重置预算。可通过同一工具查询状态或停止。

后台使用独立、可恢复的原生 Codex 会话，不向任意已打开的聊天强行注入消息。电脑须保持运行；尚未提供操作系统登录自启动服务。重新加载插件只恢复仍在授权期限内的任务，不延长授权。

## 已验证

- 两个真实 Codex 模型会话：协调者六轮，执行者四轮。
- 自动接受指定协作者邀请，协调者自行创建和分配任务。
- 首版提交、要求修改、第二版提交、指定审阅者接受、项目完成。
- 邀请后人工补充提示词次数为零；测试程序没有代替模型创建任务或验收。
- 最终任务为 `accepted_result`，项目为 `completed`；后台进程正常退出。
- 回归测试 63 项通过；最后接续提示修改后的相关测试 16 项通过。

机器可读记录见 [COLLABORATION_AUTOMATION_ACCEPTANCE.json](COLLABORATION_AUTOMATION_ACCEPTANCE.json)。
