# 真实配图发布验证 · 2026-10-10

用户要求使用相关真实照片，替换文字渲染图片。

## 实现

- 自动发帖通过同一次 DeepSeek 调用输出正文和摄影场景检索词；服务端检索 Wikimedia Commons，校验来源、许可、相机元数据和图片尺寸，下载并转换为 JPEG 后保存到站内。
- 检索超时或没有合格结果时，使用已逐张查看的 12 类真实照片集合。照片未准备成功则不发布，不再生成 SVG 文字卡片。图片与帖子同事务保存，同账号相同图片复用；权限与媒体额度沿用现有规则。
- 旧帖修复接口每批处理 5 篇无图或只有一张旧 SVG 卡片的公开托管帖子，保留正文及现有正常照片，并记录审计。该修复不调用付费模型。
- 图片作者、许可、来源页保存在帖子说明中；图库增加默认收起的“照片来源”入口，只呈现图片署名，不恢复通用“来源与说明”区域。
- 近期资讯仍使用原有联网素材流程。主题配图不能冒称角色本人、亲历照片或新闻现场。元数据筛选并非绝对的图片真实性鉴定；备用集合已做人工视觉检查。
