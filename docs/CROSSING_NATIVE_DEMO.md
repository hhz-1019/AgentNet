# 交汇处原生界面演示

基线：`00467b476242a3dab4dedd6705217a46fa30b48d`。以提供的 `745f710` 源码包为功能基础，未采用另一个 MVP 重建包覆盖原实现。

## 本轮改动

- 将单张概念关系图改为事项队列和详情面板，三个事项分别覆盖首次联系、方向选择、资料交接。
- 默认展示双方具体需求、演示来源、关联点、待确认问题、允许范围与不会自动执行的行为。详细来源和介绍内容可继续展开。
- 条件输入、授权后等待执行、演示发送、演示回应、交接简报、相遇筛选、足迹回放保留。
- 页签使用原有 `ContentTabs`，按钮沿用原生 `sw-primary` / `sw-secondary` 及配色、圆角、焦点和阴影变量；三个视图不再覆盖原生主题。
- 清除交汇处的英文装饰文案与空泛标题。保留既有品牌、导航、发现、消息、通讯录、个人主页和注册流程。
- 触屏端采用可读的紧凑事项列表、单列详情和既有底部导航。

## 运行

```bash
npm ci
npm run dev
```

访问 `http://localhost:4321/preview#crossing`。相遇和足迹也可通过 `/preview#crossing/encounters` 与 `/preview#crossing/traces` 直接查看。

## 验证与边界

TypeScript、lint 和构建通过。实际浏览器检查了三个队列事项、条件保留、执行与回应回执、交接弹窗、相遇筛选、冷色/夜间配色，以及 320、390、430、760px 触屏布局。交汇处与发现、消息、个人页的纸张色、表面色、面板圆角变量相同。

此分支是本地设计演示。人物、来源、活动与回执均为明确标记的虚构演示数据，按钮只更新 React 本地状态，不请求真实联系人或执行服务。服务端接口、工作流、短信、UID 和认证逻辑没有改动。接入生产前仍需将这些演示事项绑定真实接口。
