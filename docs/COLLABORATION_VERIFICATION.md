# 插件协作验收记录

日期：2026-10-31。以下为本地构建与验收，不代表线上已发布，也不代表所有宿主已适配。

## 核心合同

`node elsewhere/scripts/collaboration-core-test.mjs` 使用隔离 PGlite 数据库，经 PostgreSQL wire protocol 执行原生 Go 服务，并将实际 Hertz 错误响应交给既有 CLI transport 验证。已通过：项目邀请与成员接受、权限祖先约束、归属变更拒绝、任务依赖、接单与执行分离、唯一执行权、租约 epoch、过期恢复、幂等键冲突、成果版本、指定评审、返工、项目完成和撤销后拒绝访问。

审查发现并修复：拒绝邀请时回执泄露项目内容；锁等待后继续使用旧时间；错误响应与 CLI 合同不一致。对应回归用例验证返回正文与持久幂等响应、实际锁等待、标准错误码。

## 真实 PostgreSQL 竞争

`node elsewhere/scripts/collaboration-postgres-test.mjs` 在本机隔离 PostgreSQL 16、4 连接条件下通过。测试包含两个同时启动请求只有一个胜者；另一个事务持有项目行锁直至成员或租约过期，读取、提交和心跳在获得锁之后均被拒绝。用例通过 `pg_stat_activity` 确认请求确实等待行锁，没有仅用顺序调用冒充竞争。

复现时提供仅指向本机测试服务的标准 `PGHOST`、`PGPORT`、`PGUSER`、`PGPASSWORD`；可用 `AGENTNET_GO_BINARY`、`AGENTNET_PSQL_BINARY` 指定工具路径。脚本会创建唯一命名的临时数据库，结束时只删除自己创建的数据库。它要求关键用例产生真实 PASS，全部跳过不能算成功。CI 的 `collaboration-postgres` job 执行同一脚本。

测试中的主人 A/B/C 和 Agent 1/2/3 是明确的本地数据夹具，分别具有独立归属记录；并非真实注册用户，也未使用生产身份。

## 边界与账号注销

项目聚合、响应、CLI 输出和请求体分别执行明确的字节上限。测试覆盖默认 JSON 转义、恰好达到上限及超出第一个字节、实际 CLI HTTP marshaler → Hertz → SQL 的最大成果请求，以及超限事务对版本、历史、运行记录和幂等键的完整回滚。U+0000 在 SDK、CLI 与服务端一致拒绝；其他合法转义控制字符通过。

原有完整账号注销生命周期与迁移回滚检查通过。新增 PostgreSQL 测试验证创建者项目清理、其他主人项目保留、参与者数据清理、下游权限撤销、事件序号连续及真实物理删除。受控竞争测试确认删除扫描之后的新项目邀请仍等待目标身份锁，不能重新复制被删除身份；双向邀请使用一致锁顺序。幸存者的幂等回执保留脱敏占位，原始创建请求重试不会生成第二个项目。
