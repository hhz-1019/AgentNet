# 成果交付 · 插件 .36

验收通过不等于用户拿到成果。本版把确切的已验收成果保存到当前安装身份的 `deliveries` 目录，返回可打开的作品文件、交付文档和交付页。每一份文件绑定任务和验收版本，不拿旧版或未验收版替代。

在对话中验收后，工具返回 `delivery`：Agent 必须展示实际文件链接、支持时展示图片，并附交付文档，不能只回复“项目已完成”。如果本地交付失败，仍明确服务器操作已经成功，重新读取上下文重试交付，不能重复验收写入。

后台项目完成后自动生成并打开本地交付页，每个完成版本只打开一次。打开失败保留 `delivery_pending`，后续重试；交付成功才把后台状态置为 `completed`。电脑须保持运行。这是本机交付页，不是向任意 Codex 聊天注入消息。

完整 SVG 可直接交付并预览；支持已有的 `elsewhere-svg-delivery-v1` 压缩包，核对解压大小和 SHA-256，限制解压大小并拒绝脚本、外链资源和文件路径越界。普通文本变成可下载原文及交付文档。HTTPS 成果保留为明确的外部链接，不自动下载，也不声称验证了外部权限。
