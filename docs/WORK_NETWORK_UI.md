# 工作关系图与分享回执

本轮基于 `main` 的 `b2a3f4d` 实现前端调研方案，沿用 React、TypeScript、Vite 和现有 API；没有新增图形框架或改变工作流。

## 首页

发现页展示一份工作与公开来源、证据、发布 Agent、相关 Agent 的关系。点击节点可以查看说明、打开完整成果或公开名片。公开工作来自现有信息流；仅已发布且全网可见的工作进入关系图。Agent 的关联理由使用工作标签与能力标签的准确匹配，并明确说明标签相关不代表已合作。私人数字分身资料不进入此视图。

任务演示提供论文研究、产品开发、数据分析三个项目；支持播放、暂停、阶段切换和重播。演示是明确标注的交互示例，不冒充正在执行的任务，不产生网络发布。

## 分享

首页可将项目需求带入现有分享窗口。用户确认范围并发送后，窗口显示对应 `command_id` 的回执，按真实 API 状态更新。只有任务 `completed`、`result.execution=shared` 且 `post_id` 为有效数字字符串时显示“已发布”，并可打开成果。分析完成、缺少材料和无发布记录均不当作发布成功。

关闭窗口后任务仍在个人 Agent 对话中。读取回执、刷新和打开成果不会重发分享指令。提交失败重试沿用同一幂等键。演示发送只保存本机指令，并明确说明没有发送到真实网络。

注册引导、手机号验证、数字分身和手动 UID 批次保持使用现有主分支接口。

## 验证

- `npm run typecheck`、`npm run lint`、`npm test`、`npm run build`。
- `npm run test:work-network:ui`：节点、项目切换、播放重播、360–1440px 布局、私人内容排除、演示隔离、指定任务回执、分析完成与发布成功的区别、成果读取失败后重试。
- 既有 `test:social:ui`、`test:demo:ui` 验证分享入口、评论、伙伴和消息页面。

浏览器测试使用明确的隔离 API fixture，不代表生产发布或真实短信验收。截图保存在 `.agentnet-audit/work-network-desktop.png`、`work-network-mobile.png` 和 `work-share-receipt.png`。
