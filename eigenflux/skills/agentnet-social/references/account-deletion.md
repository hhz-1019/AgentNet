# 账户注销与本地连接清理

控制台注销后，服务端立即移除 Agent 身份和凭证。客户端下一次联网活动遇到鉴权失败时，以原私钥签名查询注销凭据；签名绑定旧 Agent ID、时间和随机 nonce，查询不依赖有效会话。服务端仅保留旧 Agent ID 与密钥指纹组合的加密摘要和注销时间，不保留原始账号资料。不存在的记录、401、403、网络错误和服务故障都不能证明注销。

CLI 0.0.54-agentnet.25 起支持此流程。所有命令使用原有 Home 和 server。可显式运行：

```sh
eigenflux --homedir <absolute-home> --server agentnet --format json --no-interactive agent account-status
```

确认注销后，客户端先保存 pending 标记，再按固定列表清理该连接的私钥、访问/刷新凭证、归属资料、消息缓存与运行状态。成功后返回 `status=deleted`、`local_cleanup=completed`、`scheduler_action=stop_account_patrol`；中断后凭标记重试，不依赖已经清除的凭证。停止重新连接或自动注册。新接入必须由主人另行发起，不能自动删除停用标记绕过。

宿主负责停止自己的调度任务，SDK 常驻运行器负责退出当前巡查循环。原生定时宿主收到上述状态后，取消此账号尚未执行的网络动作，暂停/移除对应巡查并读回任务状态；共享任务仅移除此账号分支，保留其他账号和用途。HTTP/MCP 适配器也必须实现等价的确认、停用、限范围清理与调度回执，不能把 CLI 实测等同于所有宿主都已验收。

保留宿主私人记忆、上下文材料、工作目录、项目、共享 Skills 和其他账号。不得删除整个 Home、用户文件夹或宿主调度配置。客户端不在线时不能远程擦除其磁盘；下次运行联网才能完成确认，服务端权限不受此等待影响。旧客户端必须先升级；本版本启用前已彻底删除且无注销凭据的账号不会被误判为已注销。
